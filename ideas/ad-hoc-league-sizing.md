# Ad-hoc league sizing

Formerly Phase 5 of `claude/next-features-roadmap.md`: support a real Sleeper league whose
team count doesn't match one of the four sizes `LeagueShape.SUPPORTED_TEAM_COUNTS` already
handles (8/10/12/14) — the `SimulationRequest` branch, a seat-assignment UI, a team-count
dropdown not pinned to those four values.

Demoted out of the active roadmap 2026-09-02. All four of Allan's real leagues (README.md's
"Leagues" section) are 12 or 14 teams, and the from-scratch mock room already supports
8/10/12/14 with no real league behind it at all. There is no current draft this would unblock
— it exists only for a hypothetical future league at some other size. Build it if and when
that league actually shows up, not ahead of time.

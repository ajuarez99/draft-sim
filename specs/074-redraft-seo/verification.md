## Defects found during verification

- **V-01 (HIGH) - the link-preview image still says "Time Machine".** `web/public/og-image-tm.png` (copied to `dist/`) reads "BALL KNOWERS / Time Machine / ... / Free with a Sleeper username". Repro: open `web/dist/og-image-tm.png` (copy at `screens/17-og-image-still-old-name.png`). Fix: render the PNG from the already-reworded SVG.
- **V-02 (MEDIUM, accessibility) - focus falls to `<body>` on any client-side navigation into a season page.** Repro: on `/nba/2014-15` click "Next season: 2015-16" (or a year pill on `/nba`), then read `document.activeElement`: `BODY`, at 150 ms, 600 ms and 1.5 s. The same click to `/nba`, `/daily` and `/` leaves focus on the h1. Reasoned cause: `TimeMachineShell`'s effect (`web/src/components/TimeMachineShell.tsx:39-54`) focuses the h1 of the loading state (`SeasonShell`, `SeasonPage.tsx:296`); when the data arrives the page renders a different h1 (`SeasonPage.tsx:395`) and the focused node is removed. Fix C6 is therefore not working on the one route review-fixes.md names. Scroll-to-top does work.
- **V-03 (LOW, local builds only) - a build made with `REDRAFT_ALLOW_EMPTY_SPORT=1` still talks about football.** Static `/` and `/daily` carry a "Football ... Play" daily card that disappears on mount; h1, title and copy say "NBA or NFL"; mounted `/daily` says "No football game was dealt yesterday." The tile, footer link, index and sitemap entries are correctly absent. Production has both sports, so this only affects the flag's own use.
- **V-04 (LOW, reasoned, not observed) - a signed-in visitor is served the guest markup until the bundle mounts.** `boot.js` still sets `html[data-bk-user]` and the CSS still hides `.landing-prerender`, but none of the new static pages has that class (`grep -c landing-prerender` is 0 in `index.html`, `daily.html`, the season pages). So the static top bar "Sign in", the "Keep your games" form and the guest state line show until the roughly 1 MB bundle runs. - **V-06 (LOW) - `.tm-pick.behind` arrow measures 4.45:1.** Above 3:1 for a graphic, just under 4.5:1 if judged as text (13px, weight 900). The estimate in review-fixes.md was 4.7.
